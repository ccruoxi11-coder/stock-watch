# A股盯盘工具：安装、使用与更新教程

本文适用于 Windows 10/11。项目数据仅供学习和辅助观察，不构成投资建议。

## 1. 首次安装

### 方法一：下载 ZIP

1. 打开 GitHub 项目首页。
2. 点击 `Code` → `Download ZIP`。
3. 解压到不含特殊权限限制的目录，例如 `D:\stock-watch`。
4. 安装 Python 3.10 或更高版本，安装时勾选 `Add Python to PATH`。
5. 双击 `启动盯盘.bat`。

首次启动会自动创建 `.venv` 并安装依赖。成功后浏览器会打开看板，后台采集器也会隐藏运行。

### 方法二：使用 Git 克隆

```powershell
git clone https://github.com/ccruoxi11-coder/stock-watch.git
cd stock-watch
.\启动盯盘.bat
```

## 2. 配置企业微信通知

复制配置模板：

```powershell
Copy-Item .env.example .env
```

编辑 `.env`：

```env
WECOM_WEBHOOK=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的机器人key
```

`.env` 已被 Git 忽略，不会上传到 GitHub。不要把 Webhook 写进 README、截图或 Issue。

## 3. 日常使用

1. 双击 `启动盯盘.bat`。
2. 在左侧填写六位股票代码并保存。
3. 设置全局涨跌幅、资金流、连续流入和盘中急变阈值。
4. 在“单股规则”中设置分组、标签、突破价、跌破价、5分钟异动、成交速度和冷却时间。
5. 在“个股详情”查看分钟价格历史。
6. 在“告警复盘”查看告警后5、15、30、60分钟表现。

关闭浏览器不等于停止监控。需要完全停止时双击 `停止盯盘后台.bat`。

## 4. 本地数据位置

以下内容只保存在本机，不上传 GitHub：

| 内容 | 位置 |
|---|---|
| Webhook与环境配置 | `.env` |
| SQLite数据库 | `data/watch.db` |
| 自动备份 | `data/backups/` |
| 后台日志 | `data/logs/` |
| Python虚拟环境 | `.venv/` |

升级前可双击 `备份数据库.bat`。备份文件不会被代码更新覆盖。

## 5. 从 GitHub 获取后续优化

如果使用 Git 克隆，先停止后台，再更新代码：

```powershell
.\停止盯盘后台.bat
git status
git pull --ff-only
.\启动盯盘.bat
```

`git pull --ff-only` 不会静默覆盖存在冲突的本地代码。`.env`、`data/` 和 `.venv/` 都在忽略列表中，正常更新不会删除这些本地内容。

如果使用 ZIP：

1. 双击 `备份数据库.bat`。
2. 下载新版 ZIP 并解压到新目录。
3. 将旧目录的 `.env` 和整个 `data` 目录复制到新目录。
4. 双击新版 `启动盯盘.bat`。

数据库结构会自动迁移，不需要手动删库。

## 6. 将本地优化继续上传到同一仓库

项目维护者可执行：

```powershell
git status
git add .
git commit -m "描述本次优化"
git push origin main
```

每次上传前建议执行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m py_compile app.py worker.py monitor_service.py db.py rules.py
```

只要继续向同一分支推送，GitHub 上的文件就会更新为最新版本，同时保留全部提交历史，可以随时查看或回退旧版本。

## 7. 故障诊断

双击 `诊断报告.bat`，检查：

- Python与Windows版本；
- 自选股数量；
- 数据库大小与记录数量；
- 后台采集器状态；
- 通知队列状态。

诊断报告不会输出企业微信 Webhook。接口异常时也可运行：

```powershell
.\.venv\Scripts\python.exe test_data.py
```

## 8. 常见问题

### 页面关闭后为什么还有 Python 进程？

后台采集器会继续盯盘，这是预期行为。运行 `停止盯盘后台.bat` 即可安全停止。

### 更新代码会不会丢失告警和规则？

不会。告警、单股规则和历史记录存放在被 Git 忽略的 `data/watch.db` 中。但仍建议更新前备份。

### Git 提示本地文件冲突怎么办？

不要使用 `git reset --hard`。先备份项目并运行 `git status`，确认哪些代码被本地修改，再决定提交、暂存或手工合并。

### 企业微信没有收到消息怎么办？

检查 `.env`、侧边栏推送开关、通知静默时段，以及“系统维护”中的通知队列。必要时点击“测试企业微信通知”。
