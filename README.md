# A股盯盘资金流监控

[![tests](https://github.com/ccruoxi11-coder/stock-watch/actions/workflows/tests.yml/badge.svg)](https://github.com/ccruoxi11-coder/stock-watch/actions/workflows/tests.yml)

本地 Python + Streamlit + SQLite，行情/资金流来自 **东方财富接口（行情备用腾讯源，免费，接口可能变更）**。

> 仅供学习与辅助盯盘，不构成投资建议。数据可能有延迟或缺失。

完整的新手安装、企业微信配置、数据备份和后续版本覆盖更新说明见：[使用与更新教程](docs/使用与更新教程.md)。

## 目录结构

```text
stock-watch/
├── app.py              # Streamlit 看板（主入口）
├── worker.py           # 独立后台采集、规则计算与通知
├── monitor_service.py  # 页面/后台共享的监控循环
├── market_clock.py     # 交易时段与数据时效判断
├── collector.py        # 东财/腾讯拉行情 + 主力净流入
├── rules.py            # 涨跌幅 / 资金流告警规则 + 去重
├── notify.py           # 企业微信机器人推送
├── db.py               # SQLite 告警记录
├── watchlist.py        # 自选股 JSON 读写
├── config.py           # .env 配置
├── watchlist.json      # 自选股列表（可手改）
├── test_data.py        # 验证数据接口
├── requirements.txt
├── .env.example
└── data/               # 运行后自动生成 watch.db
```

## 实现步骤（已完成 MVP）

1. 自选股可编辑（侧边栏 / `watchlist.json`）
2. 行情表：最新价、涨跌幅%、成交额
3. 资金流明细：主力净流入 + 超大/大/中/小单拆分 + 主力占成交额比 + 分时主力趋势图
4. 主力连续 N 日净流入/流出统计（近 20 个交易日）
5. 五类告警（写入 SQLite，同股同类型每天去重 1 次）：
   - `|涨跌幅| > 阈值%`
   - `|主力净流入| ≥ 阈值（亿）`
   - `|主力净流入占成交额| ≥ 阈值%`
   - `主力连续同向 ≥ N 天`
   - `近 N 分钟主力资金急变 ≥ 阈值`（交易时段生效）
6. 配置企业微信 Webhook 后推送
7. 自动刷新（需 Streamlit ≥ 1.33 的 `st.fragment`）
8. 行情数据源、行情时间与实时/陈旧状态展示
9. 企业微信失败通知指数退避重试，并显示通知队列状态
10. 沪深北市场代码识别；节假日陈旧行情自动停用盘中急变判断
11. 独立后台采集器：关闭浏览器后继续盯盘和通知
12. 页面优先读取 SQLite 行情快照，后台失联时自动回退直连接口
13. 单股规则：分组、标签、备注、暂停、突破价、跌破价、独立资金阈值
14. 组合规则：5 分钟价格异动 + 主力同向、5 分钟价格异动 + 成交速度
15. 告警等级、单股冷却时间、跨午夜通知静默时段
16. 分钟历史、个股价格详情、告警后 5/15/30/60 分钟表现复盘
17. SQLite WAL、日志轮转、每日自动备份、历史自动清理和诊断报告

## 稳定性说明

- 告警去重和事件入库在同一个 SQLite 事务内完成，避免事件丢失。
- 通知状态分为待发送、已发送、失败待重试和已跳过；企业微信失败后最长每 60 分钟重试。
- 未启用企业微信时产生的告警仍会记录，但标记为已跳过，之后启用时不会补发旧消息。
- HTTP 请求复用连接池，并在直连和系统代理之间自动切换。
- 后台采集器有单实例锁和 30 秒心跳，重复启动不会产生多个采集进程。
- 交易时段按设置的刷新频率采集，盘前/午休 60 秒，其他时间 5 分钟。
- 分钟历史按“每股每分钟一条”去重，默认保留 30 天，避免数据库无限增长。
- 后台日志位于 `data/logs/worker.log`，单文件 2 MB，轮转保留 5 份。
- 每天 16:00 后自动备份一次数据库，位于 `data/backups/`，保留最近 10 份。

## 快速开始

**最简单：双击** `E:\stock-watch\启动盯盘.bat`

启动脚本会在后台隐藏启动采集器，再打开 Streamlit 看板。关闭浏览器或看板窗口后，后台采集器仍会继续运行；需要完全停止时双击 `停止盯盘后台.bat`。

或手动：

```bash
cd E:\stock-watch
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt

# 先测数据通不通
python test_data.py
# 或双击 测试数据.bat

# 启动看板
streamlit run app.py

# 另开一个终端启动后台采集器
python worker.py

# 安全停止后台采集器
python stop_worker.py
```

后台工作方式：

1. 页面把阈值、刷新频率和推送开关写入 `runtime_config`。
2. `worker.py` 读取配置和自选股，采集行情、计算规则、发送通知。
3. 最新结果写入 SQLite 单例快照，避免数据库无限累积行情记录。
4. 页面检测到有效心跳后只读本地快照；后台不可用时自动使用原直连模式。

## 单股规则与组合告警

看板底部“单股规则”页可配置：

- 分组、标签、备注和是否启用；关闭后该股票暂停所有告警。
- 突破价和跌破价。
- 5 分钟涨跌幅阈值。
- 近 5 分钟成交额速度相对当日日内均速的倍数。
- 主力净流入占成交额阈值。
- 告警等级和重复提醒冷却分钟数。

当短时价格与主力资金方向一致，或短时价格与成交速度同时异常时，会生成“紧急”组合告警。侧边栏可配置通知静默时段，例如：

```text
11:30-13:00,22:00-08:00
```

静默期间事件仍会记录，但不会补发旧通知。

## 复盘与维护

- “个股详情”展示最近 240 条分钟价格记录。
- “告警复盘”计算告警后 5、15、30、60 分钟的价格变化；没有足够且时间相近的数据时保持为空，避免跨交易日误算。
- “系统维护”可查看数据库规模、采集器健康状态、立即备份或清理过期数据。
- 双击 `备份数据库.bat` 可手工备份。
- 双击 `诊断报告.bat` 可输出不包含 Webhook 的本地诊断信息。

运行本地自动化测试：

```bash
python -m unittest discover -s tests -v
```

浏览器会打开本地页面。交易时段数据更全；休市时仍可能有昨收/静态数据。

### 若报连接失败 / 连不上东财

程序每次请求会自动在「直连」和「系统代理」两条通道间切换重试，行情还有腾讯备用源。
东财偶尔会对高频 IP 临时限流几分钟，稍等自动恢复；双击 `测试数据.bat` 可随时自检。

## 企业微信推送

1. 企业微信群 → 添加群机器人 → 复制 Webhook
2. 复制配置文件并填写：

```bash
copy .env.example .env
```

编辑 `.env`：

```env
WECOM_WEBHOOK=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的key
FUND_FLOW_THRESHOLD=50000000
PCT_THRESHOLD=3.0
REFRESH_SECONDS=60
```

3. 侧边栏勾选「启用企业微信推送」
